# Agents

This document describes the agents that will be implemented in the Umawiacz project.

## Agent Types

1. **BasicAgent**
2. **ResearcherAgent**
3. **PlannerAgent**
4. **CoderAgent**

## Agent Responsibilities

### BasicAgent
- Provides basic information and answers to simple questions
- Responds to general inquiries about the project
- Handles straightforward user requests

### ResearcherAgent
- Conducts research on topics related to the project
- Gathers information from external sources if needed
- Analyzes and summarizes research findings

### PlannerAgent
- Creates plans for implementing features or solving problems
- Breaks down complex tasks into smaller steps
- Estimates time and resources required for tasks

### CoderAgent
- Writes code based on implemented plans
- Follows coding standards and best practices
- Tests the code to ensure it works as expected
